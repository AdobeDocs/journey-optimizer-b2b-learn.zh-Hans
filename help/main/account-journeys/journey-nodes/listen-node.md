# 侦听事件节点

在[!DNL Adobe Journey Optimizer B2B Edition]中使用[!UICONTROL 侦听事件]节点在事件发生时推进历程。 比较帐户和人员事件，定义匹配条件，并配置超时以控制历程等待的时间。

>[!VIDEO](https://video.tv.adobe.com/v/3443219/?quality=12&learn=on)

## 侦听节点要点

本视频涵盖以下主题：

* 帐户事件与人员事件之间的区别。
* 匹配事件触发器的条件。
* 指定时间内未发生的事件的超时设置。

## 相关文档

有关受支持的事件、配置步骤和超时选项，请参阅用户指南[&#128279;](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/journeys/journey-nodes/listen-for-event-nodes){target="_blank"}中的侦听事件。
