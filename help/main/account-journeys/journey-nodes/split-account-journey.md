# 拆分和合并路径

了解如何使用Adobe [!DNL Journey Optimizer B2B Edition]中的拆分和合并路径节点，根据条件通过帐户历程路由帐户或人员。 此视频介绍帐户和人员拆分、路径优先级、默认路径和合并。

本教程适用于使用[!DNL Journey Optimizer B2B Edition]为不同区段和购买组成员个性化基于帐户的营销历程的营销专业人员和历程设计人员。

>[!VIDEO](https://video.tv.adobe.com/v/3443266/?captions=chi_hans&learn=on&enablevpops)

了解如何：

* 了解帐户路径与人员路径之间的区别。 帐户路径支持帐户和人员步骤、嵌套和合并。 人员路径仅支持人员操作，无法嵌套，且会自动关闭。
* 将拆分路径节点添加到历程并选择按帐户或人员（最多25个路径）拆分。
* 使用帐户属性、配置的自定义对象或匹配的购买组属性定义路径条件。
* 通过用&#x200B;_帐户购买团体准备情况来路由帐户，该帐户与购买团体_&#x200B;筛选器匹配。
* 设置路径优先级。 从上到下评估路径，每个帐户遵循其匹配的第一个路径。
* 使用其他帐户或其他人作为不匹配受众的默认路径。
* 将操作和事件添加到每个帐户路径，然后使用合并路径将它们重新联接。
* 由人员使用人员属性、帐户 — 人员关系属性、购买组成员资格、自定义对象和事件历史记录（具有回顾窗口、频度和不活动筛选）进行拆分。
* 了解自动关闭拆分路径节点如何让用户返回到帐户历程。

有关详细信息，请参阅用户指南中的&#x200B;_[拆分和合并路径](https://experienceleague.adobe.com/zh-hans/docs/journey-optimizer-b2b/user/journeys/journey-nodes/split-merge-paths-nodes)_。
