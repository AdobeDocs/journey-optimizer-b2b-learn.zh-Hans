# 在[!DNL Journey Optimizer B2B Edition]中购买群

了解购买组如何在[!DNL Adobe Journey Optimizer B2B Edition]中组织人员做出B2B购买决策。 此视频介绍您需要的组件、如何准备购买组创建作业以及如何评估准备情况。

本教程面向营销人员和管理员，他们将[!DNL Journey Optimizer B2B Edition]用于基于帐户的营销，并希望定位正确的利益相关者并限定帐户。

>[!VIDEO](https://video.tv.adobe.com/v/3433078/?learn=on&enablevpops)

了解如何：

* 定义四个构建块：角色模板、解决方案兴趣、帐户受众和阶段模型。
* 打开“帐户”下的“购买组”工作区，并浏览清单。
* 查看实时角色模板，包括条件、权重、优先级和要求。
* 将角色模板和可选阶段模型连接到解决方案兴趣。
* 通过选择解决方案兴趣和客户受众来创建购买组，然后监控创建作业。
* 评估购买组的完整性、参与度和意图，并识别缺少的角色，如从业者和影响者。
* 查看和更新购买组成员。 手动更新优先于历程操作和系统作业。
* 使用角色分析可按日期范围过滤，比较各个角色的客户获取和参与度。

有关详细信息，请参阅用户指南中的&#x200B;_[购买群组](https://experienceleague.adobe.com/zh-hans/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-overview)_。
