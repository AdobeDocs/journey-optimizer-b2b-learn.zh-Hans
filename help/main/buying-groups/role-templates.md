# 购买群组角色模板

了解如何在[!DNL Adobe Journey Optimizer B2B Edition]中生成角色模板。 这些模板定义了参与购买决策的人员、如何为人员分配角色，以及完成购买组的条件。 本视频介绍模板创建、角色配置和发布。

本教程面向营销人员和管理员，他们将[!DNL Journey Optimizer B2B Edition]用于基于帐户的营销，并希望在每个帐户中定位适当的利益相关者。

>[!VIDEO](https://video.tv.adobe.com/v/3433079/?learn=on)

了解如何：

* 打开购买组下的角色模板清单，并将草稿模板与实时模板区分开来。
* 使用唯一的名称和描述创建新的角色模板。
* 配置角色，包括其权重、自动分配和完整性要求。
* 为每个角色定义分配条件，如职位匹配。
* 要包括所有参与者，请添加更多角色，如决策者、从业者和影响者。
* 设置角色优先级，以便将人员分配到其条件匹配的第一个角色。
* 使用完整性分数设置设置设置每个角色所需的成员数。
* 发布模板，以便其状态更改为“实时”状态，并且可供解决方案关注者使用。

有关详细信息，请参阅用户指南中的[购买群组角色模板](https://experienceleague.adobe.com/zh-hans/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-role-templates)。
